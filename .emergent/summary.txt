<original_problem_statement>
The user wants to build a mobile application with a backend system to increase tax compliance. Consumers scan QR codes on tax receipts to earn entries into prize draws.

**PRODUCT REQUIREMENTS:**

**1. Mobile Application:**
*   **User Auth:** Phone number &amp; OTP verification, then create a password. (User specified JWT).
*   **Receipt Scanning:** Use the camera to scan QR codes from tax receipts.
*   **Scan Feedback:** Instant validation (valid, invalid, duplicate).
*   **User Dashboard:** Show stats like total scans, valid scans, entries earned, and scan history.
*   **Draws &amp; Rewards:** Display draw periods, user's chances, and past winnings.
*   **Push Notifications:** For scans, draws, and winners.
*   **Education Section:** Information on tax compliance.

**2. Backend System:**
*   **Scan Management:** Store and validate all scan attempts, preventing duplicates.
*   **Revenue Authority Integration:** A (currently mocked) API to verify QR codes.
*   **Draw Engine:** Configurable draw rules and randomized winner selection.
*   **Admin Dashboard:** Real-time statistics, user management, and draw management.
*   **Fraud Prevention:** Detect and flag suspicious behavior.

**3. Admin Portal:**
*   A web-based UI for admins to manage the platform.
*   Features: Dashboard, User Management, Draw Management, Analytics, Scan Records, Fraud Detection.
*   **Settings:** Admins should be able to add/manage countries where draws take place, including currency and other related settings.
</original_problem_statement>
