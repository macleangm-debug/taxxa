**original_problem_statement**:
The user wants to build a mobile application with a backend system to increase tax compliance. Consumers scan QR codes on tax receipts to earn entries into prize draws.

**PRODUCT REQUIREMENTS:**

**1. Mobile & User Web Application:**
*   **User Auth:** Phone number & OTP verification.
*   **UI/UX:**
    *   All user-facing web pages must be mobile-friendly.
    *   Display currency dynamically based on the user's country.
*   **Draws & Rewards:**
    *   Display draw periods with specific dates and times.
    *   Display prizes, including images for item-based prizes.
    *   The draw selection mechanism must be secure, auditable, and provably fair.

**2. Admin Portal (Web):**
*   **UI/UX:**
    *   A professional, enterprise-grade layout with a permanent sidebar navigation.
    *   The dashboard should be data-visualization heavy, focusing on charts and graphs.
    *   Content on pages should utilize the full page width effectively.
*   **Dashboard:**
    *   Admins must be able to switch between countries using a dropdown.
    *   All dashboard data must update to reflect the selected country.
*   **Draw Management:**
    *   Admins must be able to create, edit, and delete draws.
    *   Draw creation should use intuitive date and time pickers.
    *   All destructive actions (delete, complete) and creation actions must have confirmation modals.
    *   Admins must be able to configure prizes (money or items) and edit/delete prizes within a draw.
    *   Admins must be able to view a verifiable audit report for each completed draw.
*   **Settings:**
    *   Admins should be able to add/manage countries and their local currencies.
